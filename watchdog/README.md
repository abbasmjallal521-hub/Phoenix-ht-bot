|---|---|---|
| 🤖 بوت الإشارات على GitHub | كل 5 دقايق | إذا وقف، بيرجّعه يشتغل لحاله. إذا وقع أو ضل يوقع، بيبعتلك |
| 📣 القناة | كل ساعة | إذا البوت ما عاد يقدر ينشر بالقناة، بيبعتلك شو لازم تصلّح |

- كل مشكلة بتوصلك **مرة وحدة**، وإذا طوّلت بتوصلك تذكرة كل 4 ساعات، وبس تنحل بيوصلك ✅.
- قبل ما يبعت تحذير بيرجع يفحص بعد 5 دقايق، كرمال ما يزعجك على شي عابر.
- ما بيلمس كود البوت ولا إعداداته ولا الـstate تبعه. بيقرأ بس، وبيرجّع يشغّل البوت متل ما بيعمل الـschedule.

## أول شي: بوت لحاله للتحذيرات (دقيقتين)
هيك التحذيرات بتوصلك بشات لحالها وما بتختلط مع الصفقات، وإذا بوت الإشارات نفسه خرب، المراقب بيضل يقدر يخبّرك.

1. بالتلغرام فوت عـ **@BotFather** واكتب `/newbot`.
2. الاسم: `Phoenix Watchdog`. اليوزر لازم يخلص بـ `bot`، متل `PhoenixHAZ_Watchdog_bot`.
3. BotFather بيعطيك توكن. **ما تبعته لحدا ولا تحطه بأي شات.**
4. GitHub › Phoenix-ht-bot › Settings › Secrets and variables › Actions › **New repository secret**
   › Name: `WATCHDOG_BOT_TOKEN` › الصق التوكن › Add secret.
5. فوت عالبوت الجديد بالتلغرام واكبس **Start**.

بلا هالخطوة المراقب بيشتغل عادي، بس بيبعت من بوت الإشارات. وإذا نسيت تكبس Start، بيذكّرك مرة باليوم من بوت الإشارات.

## الكلفة
ببلاش. بيشتغل على GitHub Actions بالريبو هيدا (public، يعني الدقايق ما إلها حد)، والتلغرام ببلاش.
كل تشغيلة بتطوّل حوالي 5 ساعات و40 دقيقة، وبعدين هو بيشغّل يلي بعدها، فما بيستنى الـschedule تبع GitHub يلي بيتأخر ساعات.

## الإعدادات (Settings › Secrets and variables › Actions)
بيستعمل نفس الـsecrets تبع البوت. وفي كمان:

| Secret | لشو |
|---|---|
| `WATCHDOG_BOT_TOKEN` | توكن بوت المراقب (شوف «أول شي» فوق). بلاه بيبعت من بوت الإشارات |
| `APP_URL` | رابط تطبيق Phoenix HT Trading، كرمال يفحصه. منحطه secret لأن الريبو public |
| `LINK_URL` | رابط صفحة الروابط، إذا بدك ياه يفحصها كمان |
| `WATCHDOG_CHAT_ID` | الـid تبعك عالتلغرام. **بس إذا الرسائل ما وصلتك**. بالعادة بيعرفك لحاله لأنك صاحب البوت |

بتقدر تغيّر هودي من `.github/workflows/watchdog.yml` (بالـenv): `WATCHDOG_MORNING` (وقت التقرير)، و`AUTO_RESTART=0` (ما يرجّع البوت لحاله)، و`NOTIFY_RESTARTS=1` (رسالة مع كل مرة بيرجّع فيها البوت).

## زدت أو غيّرت secret؟
المراقب بيقرا الـsecrets بس لما تبلّش التشغيلة، فبياخد الجديد لحاله بالتشغيلة الجاية (أقصى شي 6 ساعات). إذا بدك ياه فوراً:
1. GitHub › Actions › **Phoenix Watchdog** › افتح التشغيلة الشغّالة (الصفرا) › **Cancel workflow**.
2. بعدين **Run workflow** (بلا ما تعلّم على report_now).

ذاكرته ما بتضيع، بتنحفظ حتى لو عملت Cancel. وكمان أي تعديل عالمراقب بينعمله merge بيرجّع يشغّله فوراً.

## تجربة
GitHub › Actions › **Phoenix Watchdog** › Run workflow › علّم على **report_now** › Run.
بيوصلك التقرير خلال دقيقة، بلا ما يأثر عالمراقب الشغال. وبما إنها تشغيلة جديدة، بتاخد الـsecrets الجديدة دغري: هيدي أسرع طريقة تتأكد إنه بوت المراقب الجديد شغّال.

## انتبه
- إذا بدك توقف البوت **عن قصد**: Actions › Phoenix HT Bot › **Disable workflow**. إذا عملت Cancel بس، المراقب رح يرجّعه يشتغل.
- إذا يوم ما وصلك تقرير الصبح، يعني المراقب نفسه واقف: شوف Actions › Phoenix Watchdog.

## 📧 مدير الإيميلات
بيشتغل جوّا المراقب، وبيبعتلك من نفس بوته. كل 10 دقايق بيشيّك عالـGmail:

- **بيدقّلك فوراً** عالإيميلات المهمة: تنبيهات أمان Google، تنبيهات GitHub وتسجيلات الدخول (وتشغيلات فاشلة بالريبوهات التانية؛ تبع البوت المراقب أصلاً عم يشوفها)، Render إذا فشل deploy أو وقفت خدمة، Firebase وGoogle Cloud، وCapital.com وOneRoyal (مارجن، سحب وإيداع، أمان الحساب). وأي إيميل فيه كلمات أمان متل «Security alert» أو «تنبيه أمان».
- **بيتأكّد إنه المرسل حقيقي** من فحص Gmail نفسه (DMARC/DKIM). إذا مش متأكد، بيحطلك ⚠️: ما تكبس أي رابط قبل ما تتأكد.
- **الباقي** بيعدّلك ياه بتقرير الصبح: كم إيميل ومن مين.
- بيقرا **المرسل والموضوع بس**. ما بيفتح الإيميل، وما بيعلّمه مقروء، وما بيمحي ولا بينقل شي. وما بيكتب بالـlog ولا مرسل ولا موضوع، لأن الريبو public.

### التشغيل (5 دقايق)
1. لازم يكون حساب Google عليه **2-Step Verification** (myaccount.google.com › Security).
2. فوت على **myaccount.google.com/apppasswords** › اكتب اسم: `Phoenix` › Create.
3. Google بيعطيك كلمة سر من 16 حرف. **هيدي مش كلمة سرّك الأصلية**، وما تبعتها لحدا ولا بأي شات.
4. GitHub › Phoenix-ht-bot › Settings › Secrets and variables › Actions › **New repository secret**، مرتين:
   - Name: `GMAIL_ADDRESS` › الإيميل تبعك (…@gmail.com).
   - Name: `GMAIL_APP_PASSWORD` › الـ16 حرف (عادي إذا فيهن فراغات).
5. رجّع شغّل المراقب ليقرا الـsecrets (شوف «زدت أو غيّرت secret؟» فوق). بيوصلك «📧 مدير الإيميلات صار شغّال».

بتقدر تلغيه بأي وقت: امحي الـApp Password من نفس الصفحة عند Google، أو امحي الـsecrets.
بدك إيميلات من جهة تانية تكون دايماً مهمة (متل بنك أو PayPal)؟ حط الدومين تبعها بـ`MAIL_WATCH` بـ`.github/workflows/watchdog.yml`، مفصولين بفاصلة.
